Why Discogs matters

The release is the product surface.

For collectors, the album title is not enough. Groovie keeps release version, label, format, country, barcode, condition and personal collection state in one focused view.

Marketplace context

Market data is useful only when it answers a collector question.

Groovie does not need to look like a shop. It can show availability, price movement and wantlist matches as context for the record already being inspected.

Data and persistence

The login is not decoration. It is the app boundary.

Persistent Discogs state. Username and token state decide whether the user enters the real app.

Cached responses. Barcode and text search can reuse Discogs responses without pretending the data is local-only.

Native workflow. Fast checks belong to scanner/search; slower review belongs to collection and release detail.
